# ShareView Studio

redesign this screen to look more polished and production-ready for the following
Build a public file-sharing viewer page. It should show a branded header area with an optional logo image, a custom accent color, and a page title. Below that, show a grid/gallery of shared files with thumbnail previews for images and file-type icons for other formats (PDF, video, zip). Each file has a filename, file size, a Preview button, and a Download button. The page has a gradient background and a centered card with a glassmorphism effect. Include a state for password-protected shares showing a password input with an Unlock button. Use Tailwind CSS, indigo as primary color, dark mode support.
